# Designer Portfolio 🎨

بورتفوليو احترافي لمصمم UI/UX، مبني بـ Next.js 16.

## 🛠️ التقنيات

- **Next.js 16** (App Router) — Full-Stack Framework
- **MongoDB + Mongoose** — قاعدة البيانات
- **Tailwind CSS v4** — التنسيق
- **next-intl** — دعم العربية والإنجليزية
- **next-themes** — الوضع الليلي/النهاري
- **Framer Motion** — الحركات

## 🚀 الميزات

- ✅ دعم كامل للعربية (RTL) والإنجليزية (LTR)
- ✅ وضع ليلي ونهاري
- ✅ لوحة إدارة كاملة (Dashboard)
- ✅ CRUD للمشاريع والمهارات
- ✅ صندوق وارد للرسائل
- ✅ تصميم متجاوب
- ✅ SEO محسّن

## 📦 التثبيت

```bash
npm install
npm run dev
```
